# Heart Disease Prediction + Heart Health Assistant (AI Chatbot)

A machine learning web application that predicts the possibility of heart disease based on patient health parameters.

The project uses a Random Forest Classifier for prediction, FastAPI as the backend API, and Streamlit for the frontend interface.

After running the risk prediction, users can open a multimodal chatbot powered by Google's Gemini API.


---

## Features

### For predictor:
* Heart disease prediction using a Random Forest model
* Interactive Streamlit user interface
* FastAPI backend for handling predictions
* Dropdown fields for categorical variables
* Input validation for numerical values
* Simple and user-friendly prediction results

### For AI chatbot: 
* Answer general heart-health questions
* Read uploaded prescriptions or medical reports (images/PDF) and summarize them
* Accept text, file, and voice input, with optional spoken replies

## Input Parameters

The application takes the following patient information:

| Parameter       | Description                           |
| --------------- | ------------------------------------- |
| Age             | Age of the patient                    |
| Sex             | Male or Female                        |
| Chest Pain Type | Type of chest pain                    |
| Resting BP      | Resting blood pressure                |
| Cholesterol     | Serum cholesterol level               |
| Fasting BS      | Fasting blood sugar                   |
| Resting ECG     | Resting electrocardiogram result      |
| Max HR          | Maximum heart rate achieved           |
| Exercise Angina | Exercise-induced angina               |
| Oldpeak         | ST depression value                   |
| ST Slope        | Slope of the peak exercise ST segment |

---

## Machine Learning Model

The project uses a **Random Forest Classifier** trained on patient health and cardiac-related features.

Categorical features are converted into numerical features using one-hot encoding before being provided to the model.

The trained model and required feature columns are saved using Python's `pickle` module.

---

## Backend API

The backend is developed using **FastAPI**.

### Start the API

```bash
uvicorn app1:app --reload
```

The API will run at:

```text
http://127.0.0.1:8000
```

FastAPI's interactive documentation can be accessed at:

```text
http://127.0.0.1:8000/docs
```

### Prediction Endpoint

```text
POST /predict
```

The endpoint accepts patient information and returns the model's prediction.

---

## Frontend

The frontend is built using **Streamlit**.

### Run the Streamlit Application

```bash
streamlit run streamlit_app.py
```

The application will normally be available at:

```text
http://localhost:8501
```

## How to Run

### 1. Clone the Repository

```bash
git clone <your-repository-url>
cd Heart-Disease-Prediction
```

### 2. Install Dependencies

```bash
pip install -r requirements.txt
```

### 3. Start the FastAPI Backend

```bash
uvicorn app1:app --reload
```

### 4. Start the Streamlit Frontend

Open another terminal and run:

```bash
streamlit run frontend.py
```

### 5. Use the Application

Enter the patient's information in the Streamlit interface and click **Predict** to receive the model's prediction.

---

## Prediction Output

The application provides one of two prediction results:

* **Normal**
* **Heart Disease**

The result is generated by the trained Random Forest model based on the provided input parameters.
